# Evidencia multiformato equivalente

Elija una modalidad autorizada por la actividad.

## Núcleo obligatorio en cualquier formato

- sistema/frontera o escenario claramente definido;
- al menos una relación termodinámica pertinente;
- supuestos y unidades;
- verificación independiente;
- conclusión propia;
- declaración de uso de IA si aplica.

## Modalidades posibles

### Texto

400–700 palabras + ecuaciones/figuras necesarias.

### Audio/video

3–5 min + transcripción + ecuaciones/figuras en archivo adjunto.

### Diagrama comentado

Diagrama legible + 250–400 palabras o narración transcrita equivalente.

### Notebook

Celdas explicativas, código reproducible, figura con etiquetas y una conclusión no dependiente de “el código corrió”.
