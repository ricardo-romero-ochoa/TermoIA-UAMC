# DUA y accesibilidad

El repositorio adopta como referencia las **CAST Universal Design for Learning Guidelines 3.0 (2024)**. El objetivo no es crear “versiones fáciles”, sino reducir barreras innecesarias conservando los mismos resultados de aprendizaje.

## 1. Múltiples medios de implicación

- Problemas conectados con células, biomoléculas, membranas y energía química.
- Elección entre dos contextos equivalentes cuando el objetivo conceptual lo permite.
- Objetivos y criterios de éxito visibles al inicio de cada actividad.
- Roles rotatorios en equipos: modelador, verificador, abogado del diablo, relator.
- Opción de trabajo individual equivalente cuando la interacción grupal sea una barrera documentada o pedagógicamente inadecuada.

## 2. Múltiples medios de representación

Cada concepto nuclear debe aparecer en al menos dos formas:

- lenguaje cotidiano disciplinado;
- diagrama de sistema/frontera;
- ecuación con definición de símbolos;
- gráfica o paisaje de energía;
- simulación o tabla;
- fenómeno biológico.

Las figuras deben tener texto alternativo o una descripción funcional. No use color como único portador de significado. Las ecuaciones importantes deben acompañarse de lectura verbal o definición de símbolos.

## 3. Múltiples medios de acción y expresión

Cuando el producto no dependa esencialmente de escribir, el estudiante puede entregar:

- texto estructurado;
- audio o video corto con transcripción;
- diagrama anotado + explicación;
- notebook comentado;
- mini-presentación accesible.

La rúbrica evalúa el mismo razonamiento termodinámico.

## 4. IA como apoyo de accesibilidad, no como sustituto cognitivo

Puede usarse IA para reformular lenguaje, generar una explicación alternativa, convertir texto en esquema o crear preguntas de práctica. El estudiante debe comprobar que la transformación conserva el significado científico.

## 5. Ruta sin IA en tiempo real

El archivo `docs/actividades/banco_salidas_ia_estudiante.md` contiene respuestas ficticias con errores típicos. Esto permite ejecutar la auditoría aun sin cuenta, conectividad o consentimiento para usar una herramienta externa.

## 6. Lista rápida de control docente

Antes de publicar una actividad, confirme:

- ¿El objetivo está explícito?
- ¿Hay al menos dos representaciones?
- ¿Existe más de una forma equivalente de demostrar aprendizaje cuando es razonable?
- ¿La actividad funciona sin una marca específica de IA?
- ¿Hay una ruta sin IA en tiempo real?
- ¿El criterio de evaluación distingue forma de presentación y dominio conceptual?
- ¿Se evita depender de color, audio sin transcripción o imágenes sin descripción?
