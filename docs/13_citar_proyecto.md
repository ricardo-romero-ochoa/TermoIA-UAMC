# Cómo citar TermoIA-UAMC

TermoIA-UAMC está diseñado para ser versionable y citable.

## Recomendación

1. Cite la versión exacta que utilizó.
2. En GitHub, use **Cite this repository** cuando esté disponible.
3. Para una versión archivada, use el DOI generado por Zenodo una vez configurada la integración GitHub–Zenodo.
4. No cite solamente la URL cambiante del sitio web si existe un DOI para la versión empleada.

Los metadatos están en `CITATION.cff`, `codemeta.json` y `.zenodo.json` en el repositorio fuente.
